 # Unicode Hex Vigenere Cipher

Two vigenere ciphers which are able to encrypt and decrypt the full unicode character set (0 to 1,114,111) using modular arithmatic.

## Features

### Full Unicode Support
Encrypts and decrypts standard text, symbols, and special characters using ord() and chr().
### 6-Digit Hexadecimal Output
Converts encrypted code points into 6-character hex strings so ciphertext can be copied and pasted across terminals  without encoding corruption.
### Passphrase Keys
Accepts any text passphrase as a repeating modular shift key.
